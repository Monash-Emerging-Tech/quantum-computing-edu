# S Gate

<LoadGateMatrix gate_id="s" />

This gate applies a rotation of $\frac{\pi}{2}$ radians about the $z$-axis to a single qubit,
including a $\frac{\pi}{2}$ phase.

It is equivalent to the following:
$$
\text{S} = \text{P}\left( \frac{\pi}{2} \right) = \sqrt{\text{Z}}
$$
See the [P](/gates/phase) and [Z](/gates/pauli-z) gates.
