# Toffoli Gate

<LoadGateMatrix gate_id="toffoli" />
<LoadCircuit circuit_id="toffoli" />

The Toffoli gate is a three-qubit quantum gate that flips a target qubit if both control qubits is in state $\ket{1}$, otherwise it leaves it unaltered.
